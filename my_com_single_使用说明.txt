my_com 串口助手 V1.0.0.1（单文件版）使用说明
==============================================

【运行环境】
- Windows 10（1809 及以上）或 Windows 11，64 位系统
- 无需安装 Qt 或任何运行库，双击 my_com_single.exe 即可使用

【首次运行】
- 程序会先解压到系统临时目录再启动，窗口出现前有 1~3 秒等待，属正常现象
- 若弹出"Windows 已保护你的电脑"（未签名程序），点「更多信息」→「仍要运行」

【串口连接】
- 使用 USB 转串口线时，需先安装对应芯片驱动（如 CH340 / CP210x，驱动由线材厂商提供）

【命令行模式（可选）】
在 cmd 或 PowerShell 中运行：
  my_com.exe cli send "@R20:0" --wait-ms 8000   查询版本
  my_com.exe cli listen --seconds 10            监听串口 10 秒
  my_com.exe cli upgrade 固件.bin --port COM5   无界面固件升级
输出在控制台，同时写 exe 旁的 cli.log

【指令表与配置】
- 指令表（调试指令面板，右栏表格）保存在 %APPDATA%\MyTeam\my_com\debug_commands.csv
  （6 列：分组/名称/发送内容/带参数/默认参数/参数提示），可直接用 Excel 双击打开编辑；
  编辑/右键修改后退出软件仍保留；换电脑时拷贝该文件，在新电脑点
  「编辑指令 → 加载表格」导入即可（同时兼容旧版 json 指令表）
- 软件勾选配置保存在 %APPDATA%\MyTeam\my_com.ini，同样不受换目录影响
