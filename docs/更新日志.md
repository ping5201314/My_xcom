# 更新日志

## my_com——V1.0.0.1 增加AI调试功能

1、新增 `src/version.h`：版本宏统一定义（MYCOM_VERSION_STR = "V1.0.0.1"），供窗口标题、程序元数据、CLI 会话标记引用

2、新增 `src/cli/climode.h` / `src/cli/climode.cpp`：命令行模式（send / listen / upgrade / relay-send 四个子命令）；自动端口（中转优先、回退直连 lastPort）；输出三通道（stdout + cli.log + 共享监视文件）；回显带「RX文本:」可读文本；outNoTrace 通道防止尾部回显重复写共享文件

3、修改 `main.cpp`：cli 子命令分发；setApplicationVersion 改引版本宏

4、修改 `src/mainwindow.h` / `src/mainwindow.cpp`：窗口标题改为「my_com 串口助手 + 版本号」

5、修改 `src/pages/terminalpage.h` / `src/pages/terminalpage.cpp`：
- 新增「监视AI会话」勾选框与 500ms 轮询（onWatchToggle / onWatchTick，白名单+状态化解析：设备回复紫色无前缀、人发送青色、AI 动作带 [AI]、CLI-ERROR 不显示、时间戳跟随「时间戳」勾选框）
- 新增 AI 中转轮询（onRelayTick：消费 %TEMP%/my_com_ai_tx.txt 用自己的串口代发）
- 新增 writeTrace：GUI 的 TX/RX、GUI-OPEN/GUI-CLOSED 写入共享监视文件
- 共享记录按完整行聚合（m_traceRxBuf 缓冲，消除碎片断句）

6、修改 `my_com.rc`：新增 VERSIONINFO 块（exe 文件属性版本 1.0.0.1）

7、修改 `CMakeLists.txt`：project 版本 1.0.0.1；cli 源文件加入构建；指令表复制改为种子复制（新增 `cmake/seed_command_table.cmake`：文件不存在才复制，构建不再覆盖用户编辑）
